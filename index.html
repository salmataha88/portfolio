About me

I build backend systems that handle duplicate events, recover from incomplete data, and enforce access controls. At EyeGo, I develop multi-tenant APIs and Kafka-based pipelines that process camera and sensor events into operational analytics and alerts. For real-time queue analytics, I use atomic Redis updates and MongoDB-backed recovery to maintain consistent minute-level metrics.

For Naseh Engine, I designed and implemented authentication and session management, wrote automated tests, and established least-privilege database access by separating read-only access to EyeGo data from Naseh's database writes.
